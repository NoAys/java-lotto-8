# java-lotto-precourse

# 🎰 로또

## 📖 기능 요구사항
> 사용자가 입력한 금액안에서 로또를 구입하고, <br>
당첨번호 및 보너스 번호를 기준으로 당첨 결과와 수익률을 출력하는 프로그램을 구현한다.

## 🎮 기본 동작
1. 사용자는 **로또 구입 금액**을 입력한다.
2. 구입 금액은 **1,000원 단위**이며, 금액에 따라 구입 가능한 로또 개수가 결정된다.
   * 예: 8,000원 입력 &rarr; 8개의 로또 구입
3. 로또 번호는 **1~45 범위**의 숫자 중 **중복되지 않게** 6개가 자동으로 생성된다.
4. 구입한 모든 로또 번호를 출력한다.
5. 사용자는 당첨 번호 6개와 보너스 번호 1개를 입력한다.
6. 각 로또를 당첨 번호와 비교하여 일치 개수 및 보너스 번호 여부로 순위를 계산한다.
7. 당첨 내역과 총 수익률을 출력한다.

## 🧮 당첨 조건 및 상금표
| 순위 | 일치 개수 | 보너스 번호 | 상금 |
| --- | --- | --- | --- |
| 1등 | 6개 | x | 2,000,000,000원 |
| 2등 | 5개 | O | 30,000,000원 |
| 3등 | 5개 | x | 1,500,000원 |
| 4등 | 4개 | x | 50,000원 |
| 5등 | 3개 | x | 5,000원 |
| 낙첨 | 그 외 | - | 0원 |

## ⚠️ 예외 처리
| 상황                   | 예외 메시지                                  |
|----------------------|-----------------------------------------|
| 구입 금액이 1,000원 단위가 아님 | [ERROR] 구입 금액은 1,000원 단위 여야 합니다.        |
| 구입 금액이 1,000원 미만     | [ERROR] 구입 금액은 1,000원 이상이어야 합니다.        |
| 당첨 번호 형식이 잘못됨        | [ERROR] 당첨 번호는 쉼표(,)로 구분된 6개의 숫자여야 합니다. |
| 중복된 당첨 번호            | [ERROR] 당첨 번호에 중복된 숫자가 있습니다.            |
| 숫자가 1~45 범위를 벗어남     | [ERROR] 로또 번호는 1에서 45 사이의 숫자여야 합니다.     |
| 보너스 번호가 중복됨          | [ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.      |

## 🧩 사용 라이브러리
* `camp.nextstep.edu.missonutils.Console`: 사용자 입력 처리
* `camp.nextstep.edu.missonutils.Console`: 로또 번호 무작위 생성

## 🧠 프로그래밍 요구사항
* JDK 21 버전에서 실행 가능해야 한다.
* `System.exit()` 호출 금지
* **들여쓰기 depth는 2단계 이하**
* **3항 연산자 금지**
* **메서드는 한 가지 역할만 수행**
* 예외는 반드시 `IllegalArgumentException` 사용
* 모든 금액은 쉼표(,) 없이 정수로 입력
* 출력 형식은 예시와 동일해야 한다.

## ⚙️ 구현할 기능 목록
* 로또 구입 금액 입력(`Console.readLine()` 사용)
* 구입 금액 유효성 검사
    * 1,000원 단위인지 확인
    * 1,000원 이상인지 확인
    * 조건 위반 시 `IllegalArgumentException` 발생 후 종료
* 로또 개수 계산 및 출력
    * 구입 금액 / 1,000으로 로또 개수 계산
    * `"n개를 구매했습니다."` 출력
* 로또 번호 자동 생성(`Randoms.pickuniqueNumbersInRange(1, 45, 6)`)
    * 1~45 범위의 중복되지 않은 6개 숫자 생성
    * 오름차순 정렬 후 출력
* 당첨 번호 입력 (`Console.readLine()` 사용)
    * 쉼표(,) 기준으로 6개 숫자 입력받기
    * 형식 및 중복, 범위(1~45) 검사
    * 잘못된 입력 시 `IllegalArgumentException` 발생 후 종료
* 각 로또의 당첨 결과 판별
    * 당첨 번호와 일치하는 개수 계산
    * 5개 일치 + 보너스 번호 일치 시 2등 처리
* 당첨 내역 출력
    * 3개, 4개, 5개, 5개+보너스, 6개 일치 결과 각각의 개수 출력
* 수익률 계산 및 출력
    * `(총 당첨금 / 구입 금액) * 100`
    * 소숫점 둘째 자리에서 반올림
    * `"총 수익률은 x.x%입니다."` 형태로 출력
* 예외 상황 처리
    * 모든 입력 오류 및 형식 위반 시 `[ERROR]`로 시작하는 메시지 출력 후 프로그램 종료
